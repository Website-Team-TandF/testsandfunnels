## 🚀 About the Project

**tests&funnels (t&f)** is a Delhi-based digital growth firm that merges artificial intelligence automation with high-end creative production. This repository contains the complete production-ready source code for the official multi-page web platform.

### Core Pillars
- **🤖 AI Agency:** Autonomous AI agents handling repetitive workflows across social media publishing, ad campaign management, sales lead nurturing/tele-calling, and operations/MIS reporting.
- **🎬 Production House:** High-converting commercial media production including product & lifestyle shoots, AI-generated visuals, UGC creator networks, and founder personal branding.
- **🌱 Incube8 Partner:** Startup incubator providing hands-on training, concept validation, acceleration, Delhi office space, and funding.
- **📈 Performance Services:** End-to-end full-funnel growth, SEO/AEO/GEO visibility optimization, and web development.

---

## ✨ Features

- **Blazing Fast Performance:** Zero heavy frameworks; built with clean, lightweight semantic HTML5, modern CSS, and vanilla JavaScript.
- **Fully Responsive:** Custom breakpoints optimized across mobile devices, tablets, laptops, and ultra-wide displays.
- **Interactive VSL & Video Showcase:** Built-in chaptered video sales letter (VSL) player, testimonial carousels, and client media showcase rails.
- **SEO & Rich Snippets:** Fully structured with Schema.org JSON-LD microdata (`Organization`, `Person`, `FAQPage`, `BreadcrumbList`).
- **Production-Ready Apache Setup:** Includes battle-tested `.htaccess` with HTTPS enforcement, clean directory routing, trailing slash handling, gzip compression, caching headers, and security rules.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic, Accessible, Schema.org JSON-LD)
- **Styling:** Vanilla CSS3 (Custom properties, CSS Grid, Flexbox, Responsive media queries)
- **Scripting:** Pure JavaScript (ES6+, zero runtime dependencies)
- **Web Server:** Apache / LiteSpeed with custom `.htaccess`
- **Hosting:** Hostinger / cPanel compatible
